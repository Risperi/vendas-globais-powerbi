# vendas-globais-powerbi
Dashboard analítico para monitoramento de vendas, margem de desconto e performance geográfica.


# 📊 Dashboard Analítico de Vendas Globais

![Preview do Dashboard](./dashboard-preview.png)

## 📌 Visão Geral do Projeto
Este projeto consiste em um painel interativo desenvolvido no **Power BI** para analisar dados de vendas globais. O objetivo é consolidar métricas essenciais de desempenho financeiro e operacional, permitindo uma leitura rápida de volumes de vendas, comportamento regional e impacto de descontos por subcategoria de produto.

---

## 🎯 Problema de Negócio
A equipe executiva necessitava de uma visão centralizada para responder às seguintes perguntas estratégicas:
1. Qual é o volume total de vendas acumulado no período?
2. Quais subcategorias demandam maiores margens de desconto?
3. Como a receita está distribuída entre as categorias principais (Suprimentos, Tecnologia, Móveis)?
4. Quais países concentram o maior volume de vendas e qual a distribuição de prioridade dos pedidos?

---

## 🛠️ Tecnologias e Ferramentas Utilizadas
* **Power BI Desktop:** Modelagem de dados, criação de medidas DAX e construção visual.


---

## 📈 Principais Métricas e Insights
* **Volume Total de Vendas:** R$ 12,64 Mi consolidados no período analisado.
* **Análise Geográfica:** Destaque de performance para mercados como Estados Unidos, Austrália e França no volume total por país.
* **Segmentação por Categoria:** Distribuição clara da fatia de vendas, permitindo identificar a relevância da linha de Suprimentos frente a Móveis e Tecnologia.

---

## 🖥️ Funcionalidades do Painel
* **Filtro Temporal Interativo:** Seleção flexível do intervalo de datas dos pedidos.
* **Filtro de Segmento:** Alternância rápida entre *Consumidor*, *Corporativo* e *Home Office*.
* **Segmentação Geográfica:** Lista dinâmica para isolamento de dados por país.
* **Mapa de Distribuição Global:** Visualização espacial dos pontos de venda.

---

## 📁 Como visualizar o arquivo
Você pode baixar o arquivo `.pbix` presente neste repositório para abrir no seu Power BI Desktop e interagir com o modelo de dados.
